# TP JavaScript – Chapitre 13 (DOM & événements)

Ce dépôt contient la **version parfaite** des 4 missions demandées :

- **Mission 1 : mot-plus-long/** – recherche du mot le plus long à partir du paragraphe `#citation` (usage de `replace` et `split`).
- **Mission 2 : palindrome/** – vérification palindrome à partir du champ `#id-mot-saisi` (usage de `toLowerCase`).
- **Mission 3 : pyramide/** – construction d'une pyramide de `n` lignes (usage de `slice`).
- **Mission 4 : tirage-au-sort/** – tirage aléatoire d'un élément du tableau de l'annexe.

## Lancement local
Ouvrez chaque fichier HTML directement dans votre navigateur :
- `mot-plus-long/mot-plus-long.html`
- `palindrome/palindrome.html`
- `pyramide/pyramide.html`
- `tirage-au-sort/tirage-au-sort.html`

## Conformité avec l'énoncé
- Structure et identifiants **strictement conformes** aux annexes.
- Méthodes exigées utilisées : `replace` & `split` (M1), `toLowerCase` (M2), `slice` (M3).
- Tableau **mangas** (M4) conforme à l'annexe, guillemets corrigés pour la compatibilité JS.

L'énoncé suggère de versionner sur GitHub et d'héberger via Netlify. Vous pouvez créer un site Netlify et pointer vers chaque page HTML. Pensez à activer l'auto‑deploy.
